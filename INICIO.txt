¿QUIEN QUIERE SER SEVILLANO?
Quiz Educativo Interactivo sobre Sevilla
================================================================================

BIENVENIDO

Este es el proyecto completo de la Aplicación "¿Quién Quiere Ser Sevillano?"
desarrollado con Python, Flask y MariaDB.

================================================================================
INICIO RÁPIDO (5 MINUTOS)
================================================================================

1. Instala las dependencias:
   pip install -r requirements.txt

2. Configura la base de datos:
   python setup_db.py

3. Ejecuta la aplicación:
   python app.py

4. Abre tu navegador en:
   http://localhost:5000

¡Listo! El quiz está funcionando.

================================================================================
PRIMEROS PASOS
================================================================================

Paso 1: REGISTRARSE
  - Entra en http://localhost:5000
  - Haz clic en "Registrarse"
  - Completa el formulario con:
    * Nombre (mínimo 3 caracteres)
    * Email válido
    * Contraseña (mínimo 6 caracteres)

Paso 2: INICIA SESIÓN
  - Usa tus credenciales registradas
  - Accede al Dashboard

Paso 3: COMIENZA EL QUIZ
  - Haz clic en "Comenzar Quiz"
  - Responde todas las preguntas
  - Cada pregunta con 4 opciones (A, B, C, D)

Paso 4: VE TUS RESULTADOS
  - Al finalizar, recibirás una puntuación
  - Verás el desglose de respuestas
  - Podrás repetir el quiz

SOLUCIÓN DE PROBLEMAS
================================================================================

Problema: "No se puede conectar a MariaDB"
Solución: Verifica que MariaDB esté ejecutándose
  Windows: Abre Services y busca MySQL/MariaDB
  Linux:   sudo service mysql start
  Mac:     mysql.server start

Problema: "Módulo no encontrado"
Solución: Instala dependencias
  pip install -r requirements.txt

Problema: "Puerto 5000 ya en uso"
Solución: Edita la última línea de app.py
  app.run(debug=True, host='localhost', port=5001)

Problema: "Error al crear base de datos"
Solución: Verifica permisos de MySQL
  mysql -u root
  Si falta acceso, usa: sudo python setup_db.py
